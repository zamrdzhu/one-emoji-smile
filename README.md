One Emoji, One Smile — an entry for make.fun's "One Emoji, One Smile"
bounty ($5 in USDC). The program sends exactly one emoji, the one most
likely to make a stranger smile.

## The emoji

🫶 — heart hands (U+1FAF6).

Two hands shaping a heart: a small, warm gesture that reads as kind and
friendly at first glance, needs no context, and works the same for a
stranger of any age or background. It is a deliberate pick rather than
the first smiley that comes to mind, and it stays friendly without
intimacy, sarcasm, or flirtation — the right warmth from someone unknown.

## Run it

Requires Python 3.13 (stdlib only, no dependencies):

```sh
python3 main.py
```

It prints the emoji and writes it to `/output/entry.txt` — exactly one
emoji character, nothing else. The grader's gate checks that file is
UTF-8 text of 1 to 8 characters; this entry writes exactly 1.

## Why this emoji

The judge weighs warmth at first glance, universality, and a choice that
feels picked rather than default. A plain smiley is the first thing that
comes to mind; heart hands are a gesture — someone offering warmth on
purpose — and they read the same way to a stranger of any age.
